仓库现场操作过程中，除了会根据需要配置流程管控、界面字段显示等控制，也会配置作业所需的单据、报表，或者进一步配置独立的个性化功能。

## 20.1. 配置自定义报表

报表是仓库管理过程中，不可缺少的功能。系统提供一些标准报表供仓库使用，更多的报表需求，可以通过自定义报表配置实现。

看板作为一种特殊展示模式的报表，也同样可以通过配置实现。

报表、看板配置时，需要先在【二次开发管理】模块中的【配置自定义报表】功能里进行注册，生成记录。然后对报表样式、内容进行配置，再经过功能授权，用户可以在【报表】模块，【个性化报表】菜单中看到具有权限的个性化报表。

所配置的看板则是在【看板】模块的【个性化看板】菜单中展示。

系统提供的报表显示内容配置，即可以做简单的列表模式查询结果显示，也可以配置成各类饼图、折线图，或者组合展示模式等复杂样式，通过【报表设计器】可以对各种复杂的报表、看板样式进行快捷的配置。

- 数据集名称

数据集名称，即报表的模板名称。

- SQL 解析

SQL 解析，可以简化带参数的 sql 语句，如 select * from rpt_value where name=':arg', arg为参数名称与参数页面的组件名称相对应，当参数页面不输入 arg值即arg为空，sql 解析会智能生成可执行的 sql语句如：select * from rpt_value where 1=1。

智能解析 SQL 语句并不能保证解析 sql正确性，如果保存 sql出现错误，建议 SQL 解析选择否。

- 分页数

分页数为 0时表示不使用分页查询，当分页数大于 0时，SQL 语句在查询时会自动增加 SQL 分页片段，不需要在 SQL 检索中写分页查询 SQL，当填写分页数如 2，程序会智能依据不同数据库添加 sql分页片段，如 mysql：select * from rpt_value limit 0, 2

### 20.1.3. 报表模板应用

报表模板配置后，需要到【配置自定义报表】功能中关联此模板。

- **模板关联**

在【二次开发管理】模块的【配置自定义报表】功能中，选择已添加的报表记录，在“报表 ID”字段，点击浏览按钮，选择所设计的报表模板，【确认】后，保存设置。

![图20-1-27](assets/p1056-img-03.jpg)

- **登录访问**

在“报表”界面，如果勾选“登录访问”，则此报表只能在登录 FLUX 系统（包括 WMS、TMS、OCP等）后才能访问。

但如果未勾选，则支持外部网页访问，可作为访客可见报表，提供链接给其他的上级领导、外部供应商、货主等查看。

- **报表授权**

- 对于系统内的报表，后续到【业务系统管理】 -【角色授权】功能中，为需要使用此报表的角色进行功能授权。

### 20.1.4. 自定义报表授权

## 20.2. 配置自定义功能

“二次开发管理”下的“配置自定义功能”功能，主要向客户提供个性化功能配置支持，可以根据现场管理需要，配置得到与系统标准功能展示模式类似的、独立表单界面的个性化操作功能，而不仅仅是基于标准功能的扩展操作、自定义操作。

配置一个独立功能时，需要先对自定义功能进行注册、配置界面元素等，然后再配置功能具体执行的逻辑。

为方便比较简单的业务模式中，可以快速配置个性化功能，对于执行逻辑配置，系统提供了标准配置模式，和简化配置模式两种不同配置模式。

配置后得到的自定义功能，同标准功能一样，通过【角色授权】功能，进行功能权限管理。

此功能无标准参数关联。

功能描述－个性化功能对应名称描述。功能发布后，在系统界面功能名称将显示为此字段配置的内容。

显示顺序－个性化功能在菜单中的显示顺序。将自定义功能加入到标准功能菜单，系统会比较标准功能的显示顺序与自定义功能显示顺序进行排序显示，而标准功能的默认显示顺序，并不是 0,1,2,3，而是“10034”这样的。可以在【业务系统管理】-【业务功能】中查看到具体显示顺序信息，相应进行配置。多个功能显示顺序相同的情况下，按功能 ID顺序显示。

- 结构选择

不同管理目标，所需要的功能界面展示模式不同，后续配置也会相应有所不同。因此配置的第一步，是选择功能结构模式。

- 一层结构

功能为查询界面、记录列表、详细信息、明细的展示模式。例如标准功能，上架规则（位 于“业务规则”模块中）就是两层结构的展示模式。

- 单证结构

功能为查询界面、记录列表、头信息、明细信息的展示模式。例如标准功能，发运订单（位于“出库操作”模块中）的展示模式。

![图 20-2-4](assets/p1083-img-03.jpg)

- SQL 语句部分用于维护功能与数据库交互 SELECT 语句。需要注意的是：

✓ 语句不要使用 SELECT * 模式，而要写具体字段名；

✓ 表名要大写，建议加上表别名；

✓ Oracle 中转换格式为：TO_CHAR(a.addTime,'yyyy-MM-dd hh24:MI:ss')AS addTime；

✓ SQL Server 中转换格式为：CONVERT(varchar(50),a.addTime,120) AS addTime。

✓ WHERE 条件处理：组织机构字段可默认配置为 表别名.organizationId ='FLUX' 或者 表别名.organizationId = '@{bizOrgId}'；

✓ 可使用系统默认参数： @{languageId}， @{bizOrgId}， @{userId}，@{bizWarehouseId}；

✓ 针对表单区域自定义的字段需要做 WHERE 条件处理的可追加 ${WHERE}，例如：表别名.udf01 ='${udf01}'，大括号{}中的 udf01 为表单配置中查询区域某文本框的字段配置值。

### 20.2.3. 简化配置模式

对于一些简单操作需求，如果按标准配置处理，所需配置的内容较多，对管理人员而言，也形成了一定的负担，因此系统还提供了一种简化配置模式，针对只需要简单录入信息，执行处理的操作模式使用，不涉及复杂的界面录入、记录编辑等功能处理。

### 20.2.4. 自定义功能授权

自定义功能配置完成后，需要针对角色配置相应的功能权限才能使用此模块。

所配置的自定义功能，活动标记为 Y 的情况下保存，系统会自动在所指定的模块中创建此功能的权限记录，未指定所属“父功能”的情况下，系统默认父功能为“自定义功能”，因此授权时，同系统标准功能，到【角色授权】中，为角色授予自定义功能权限（可参考【4.4 角色授权】章节的介绍）。

操作步骤是：

- 选择主菜单“业务系统管理”下的“角色授权”。

- 当前角色下，在”自定义功能”模块（或者所配置的父功能模块）下，勾选相应功能，并保存。

- 授权配置成功后，相应用户在浏览器中刷新后即可见新增的自定义功能。
