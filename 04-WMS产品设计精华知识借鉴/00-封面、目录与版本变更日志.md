## 1. 这套文档要解决什么问题

富勒 WMS 手册主要以“如何使用系统”为主，而我们要进一步回答“一个通用型 WMS 应该如何设计”。因此本目录做的是一次参考型产品拆解：从操作说明中提取对象、流程、状态、规则和功能，再将其整理为可供产品经理学习和设计的框架。

## 2. 参考资料范围

原始材料位于 [01-按章节拆分的md文件](../01-按章节拆分的md文件/README.md)，来源为富勒 WMS 用户手册 V6，共 23 个正文章节，原 PDF 约 541 页。

本项目保留原章节编号，方便回看原始页面。原始章节中的截图是辅助证据，不能单独证明完整业务规则；文字说明、页面字段、操作按钮和跨章节关系需要结合判断。

## 3. 设计提炼方法

每篇文档都按以下顺序思考：

1. 参考资料明确展示了什么；
2. 这些设计解决了哪个业务问题；
3. 能否抽象成通用 WMS 能力；
4. 哪些部分不宜直接照搬；
5. 为了让流程闭环，是否需要补充建议设计。

为了让每章都能直接用于产品设计，输出不只回答“富勒有什么”，还要回答“为什么需要、对象如何连接、操作后发生什么”。

| 输出层 | 最低交付内容 | 判断重点 |
|---|---|---|
| 场景层 | 使用场景、使用角色、要解决的问题 | 不把功能名称当成业务需求 |
| 流程层 | 业务流程、系统流程、关键分支 | 区分计划、执行和结果 |
| 对象层 | 中文实体对象、单据关系、任务关系 | 说明一对多、拆分、合并和来源 |
| 状态层 | 单据状态、数量状态、可执行动作 | 状态必须能解释下一步操作 |
| 数据层 | 表头、明细、关键字段和校验 | 字段服务于流程和决策，不堆字段 |
| 控制层 | 库存影响、异常、逆向、权限和审计 | 能够取消、纠错和追溯 |
| 交付层 | 功能清单、优先级、首版边界 | 区分通用能力与行业扩展 |

```mermaid
flowchart LR
    A[富勒手册章节] --> B[提取对象/流程/字段/操作]
    B --> C[判断业务目的]
    C --> D[通用化抽象]
    D --> E[建议首版设计]
    E --> F[跨模块校验与待确认]
```

## 4. 输出内容的四种标记

| 标记 | 含义 | 使用要求 |
|---|---|---|
| 参考事实 | 手册明确写出或展示 | 尽量保留章节或小节来源 |
| 归纳判断 | 从多处材料整理出的规律 | 说明判断依据，不扩大为确定事实 |
| 建议设计 | 我们面向通用 WMS 的方案 | 说明为什么增加，避免过度设计 |
| 待确认 | 资料不足或存在方案取舍 | 集中列出，不默默拍板 |

## 5. 通用 WMS 的最小闭环

```text
主数据与仓库结构
  → 规则与策略
  → 业务单据
  → 执行任务
  → 库存/容器/库位变化
  → 库存事务和业务追溯
```

任何核心单据设计，都至少要能回答：谁发起、处理什么、在哪个仓库处理、当前状态是什么、下一步谁操作、是否产生任务、是否影响库存、如何查询和纠错。

## 6. 库存影响与异常流程的适用边界

它们是条件性分析项，而非每个章节都要硬写。

- 交易性单据和执行操作：展开库存影响、任务影响、流水影响、取消和反向处理。
- 配置和主数据：分析停用、删除、引用限制、变更生效范围；没有直接库存变化时不要强行增加库存流程。
- 查询和报表：说明为只读能力，不适用库存变化和逆向操作。

## 7. 借鉴原则

- 借鉴产品思想，不照搬专有名称和实现细节。
- 借鉴“配置驱动、按仓库/货主/单据类型分层、执行留痕、复杂场景可扩展”等设计方式。
- 对于 SQL、脚本、行业插件等高实施成本能力，先判断是否属于通用 WMS 首版，而不是默认纳入。
- 业务闭环优先于功能数量，异常和反向处理优先于漂亮的页面清单。

## 8. 本章参考结论

富勒手册适合作为“成熟 WMS 功能密度和设计颗粒度”的参考，但不能直接作为通用 WMS 的需求基线。通用化设计还需要重新确定首版范围、对象边界、数据口径和跨模块状态。

## 9. 功能清单

| 优先级 | 交付内容 | 适用范围 | 说明 |
|---|---|---|---|
| P0 | 章节事实、场景、流程、对象、状态、字段和功能表 | 全部章节 | 先形成可读、可核对的设计底稿 |
| P1 | 库存影响、异常逆向、跨章节关系和待确认边界 | 交易章节为主 | 确保主链能够闭环，非交易章节明确不适用 |
| 后续 | PRD、数据字典、接口契约和验收用例 | 确定首版范围后 | 不在资料不足时提前拍板 |

## 10. 数据模型与实体对象

| 实体对象 | 中文定义 | 与其他对象的关系 |
|---|---|---|
| 参考章节 | 富勒手册中的原始证据范围 | 支撑参考事实和流程来源 |
| 业务场景 | 具体仓储问题及参与角色 | 驱动单据、任务和规则设计 |
| 业务单据 | 计划、申请、执行依据或结果凭证 | 可拆分、生成或关联任务 |
| 执行任务 | 面向人员、设备或 RF 的动作 | 回写单据、库存和事务 |
| 库存结果 | 库存余额、容器、库位和流水 | 记录当前状态与历史变化 |
| 设计结论 | 参考事实、归纳判断和建议设计 | 形成章节输出并接受后续校验 |
